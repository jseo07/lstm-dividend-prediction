# 📈 LSTM Dividend Prediction

This project predicts future **ETF dividend payouts** using a **Long Short-Term Memory (LSTM)** neural network. It leverages historical data from the `yfinance` API to capture temporal patterns in dividend trends and visualize predictions through **Tableau dashboards**.

## 🔍 Overview
- **Model:** LSTM built with TensorFlow/Keras  
- **Data Source:** Yahoo Finance (`yfinance`)  
- **Goal:** Forecast monthly dividends for selected ETFs  
- **Visualization:** Interactive Tableau dashboard for trend analysis
